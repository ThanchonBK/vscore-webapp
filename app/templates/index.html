Score the normal modes of a molecule.

Seven scores per mode — Tx Ty Tz translation, Rx Ry Rz rotation, V_S stretch character — then a label for every mode: S stretching or B bending, split at τSB. Modes that best match a rigid-body slot are listed separately as T/R candidates, yours to accept or ignore.

Both are required: a .log holds no bond list, and V_S is a sum over bonds. Connectivity is asked for, never guessed.

ORCA writes the .hess next to every frequency job. Molpro writes a Molden file with put,molden,name.molden after frequencies; other programs that write Molden work too. Neither format holds a bond list, so the bonds are uploaded, never guessed. Mass-weighted vectors are detected and converted to Cartesian displacements. Format spec →

The mode set is detected from the file. If it holds 3N modes it is taken as the complete set, translations and rotations included, and the six external modes are found among them — nothing is constructed. If it holds 3N−6 (3N−5 when linear) it is taken as vibrations only, and the six ideal T/R references are constructed and added so a real vibration is never claimed for an external slot. Any other count is refused rather than guessed at.

One file, a few kB instead of megabytes. Download one from any result page, or convert in bulk with make_vsc.py. Format spec →

What the scorer actually reads

Required

element per atom→ atomic massall 7
coordinates→ COM, principal axesall 7
displacements→ the modeall 7
bond list→ per-bond termsV_S only

Never read

Frequency never enters a score (zeroing it changes nothing) — it is used only to find degenerate sets. Reduced mass, force constant, irrep, IR/Raman intensities, charge, multiplicity, basis set — and the Cartesian Hessian, which is the largest block in a VEDA .fmt and is not used at all.
